# Симулятор «Дилемма заключенного» 
Я много читал про эту задачу из теории вероятностей. И всегда было интересно проверить это много раз. Вживую это невозможно,
но как появился шанс компьютерной модели, то я воспользовался шансом.

Краткая история: "Во время преступления попались два подельника - вы и робот. Вас рассадили по разным камерам без возможности общения.
И предлагают каждому сдать другого. У каждого есть выбор - сдать или молчать.

По итогу есть 3 варианта развития событий:
1. Оба преступника молчат, доказать преступление не удалось и обоих отпускают.
2. Оба преступника сдают друг друга, каждый получает по три года.
3. Один сдаёт другого, второй молчит. Сдающего выпускают на свободу, молчун получает пять лет тюрьмы."

Задача: получить минимальный срок (в идеале 0). Количество итераций: 10.000.

Для чистоты теста были применены 3 сценария:
1. Хороший коп. Сценарий при котором вы всегда молчите, робот делает случайный выбор.
2. Плохой коп. Сценарий при котором вы всегда сдаёте, робот также делает случайный выбор.
3. Рандом. При этом оба участника делают случайный выбор.
 

## Текущий статус проекта
В рамках текущего спринта реализовано:
* Генерация случайного выбора.
* Базовый цикл подсчета очков (лет заключения) для участников симуляции.
* Настроена интеграция с Git и GitHub для контроля версий.

## Используемые технологии
* **Python 3.13**
* Библиотека `random`
* Git / GitHub
